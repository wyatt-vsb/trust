# The Evolution of Trust

This is the original static HTML, CSS, and JavaScript game. Keep its existing
structure and bundled browser libraries; no build step, database, or secrets
are required.

## Run on Replit

- Install dependencies with `npm ci` if needed.
- Click **Run** to start the **Start application** workflow (`npm start`).
- The static server listens on `0.0.0.0:5000`; open Preview to play.
- Caching is disabled during development so edits appear after a refresh.

The entry page is `index.html`, game text is in `words.html`, and the original
translation and attribution information remains in `README.md` and `LICENSE`.
